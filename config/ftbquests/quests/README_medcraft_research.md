# Medcraft Research Questline

This folder defines the first research questline used by the pack.

Quest flow:
- Research data items are submitted in FTB Quests.
- Rewards run `/stage grant @s medcraft_<stage>`.
- FTB Teams shares quest progress and ProgressiveStages shares stages through its team integration.

If FTB Quests rewrites these files after editing in-game, keep the stage IDs and command rewards intact.
